## Lobby-Trennung (übergreifende Regel)

Freier Chat, selbst hochgeladene Bilder und keine Konten passen zusammen,
solange man die Leute kennt. Sobald der Server öffentlich läuft, gibt es damit
keine Handhabe gegen Missbrauch — wer namenlos ist, kommt nach einer Sperre
einfach neu. Deshalb gilt:

| | Private Lobby (Raumcode) | Öffentliches Matchmaking |
|---|---|---|
| Partielänge | frei einstellbar | 8–10 Min., gestaffelt (4b) |
| Chat | freier Textchat | feste Kurznachrichten |
| Avatar | selbst hochladbar | vorgegebene Figuren |

Das entspricht deiner eigenen Trennung bei der Partielänge: unter Freunden alles
frei, mit Fremden abgesichert.

## Was diese Entscheidungen bedeuten

**Online und Bots sind keine doppelte Arbeit.** Die Bots kommen zuerst und
liefern danach gleich mehrfachen Nutzen: Gegner im Einzelspiel, Auffüllung
freier Plätze online, Vertretung bei Verbindungsabbruch und Ersatzzug bei
Zeitüberschreitung.

**Der Server muss autoritativ sein.** Runecall ist ein Spiel mit verdeckten
Informationen — der Server hält die Wahrheit und schickt jedem Client
ausschließlich dessen eigene Hand. Ein Client, der den kompletten Zustand
kennt, ist ein Client, mit dem man betrügt. Das bestimmt den Aufbau von Anfang
an, nicht nachträglich.

**60 einzeln definierte Kartenmotive sind die größte Einzelaufgabe.** Nicht das
Erzeugen ist die Arbeit, sondern der einheitliche Stil über alle 60 und die
Lesbarkeit: Zahl und Rune müssen auf einer vollillustrierten Karte bei
Handygröße sofort erfassbar bleiben. Das begrenzt, wie viel Bild pro Karte
überhaupt möglich ist.

**Matchmaking braucht einen öffentlichen Server.** Der Raumcode funktioniert
sofort im WLAN. Das Matchmaking wird mitgebaut, ist aber erst sinnvoll, sobald
der Server öffentlich erreichbar ist. Lokal oder gehostet ist ein Schalter beim
Starten, keine zweite Bauweise — die Entscheidung kann später fallen.

**Zwei Sprachen von Anfang an** heißt: kein Text steht im Code. Alle Texte
liegen gebündelt und werden über einen Schlüssel geholt. Das ist beim Bauen
kaum Mehraufwand, nachträglich aber eine Schleifspur durch jede Datei.
